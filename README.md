master v5.8.5 (2025-11-17)
1. 新增L2节点支持，详细查看http://doc.cdnfly.com/ruhepeizhiL2jiedian.html (注意：设置后，之前添加的网站要手动启用一下才会生效L2)

9. 修复当节点为双栈网络，即ipv4和ipv6时，开启入口IP回源可能出现的bug

12. 修复添加IP到线路组后，并快速修改权重值，权重值不生效的bug
